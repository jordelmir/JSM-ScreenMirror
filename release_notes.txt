v1.7 — Permission Loop Fix + Signed Bundle

### Bug Fix
- **Fixed infinite permission loop:** `CGPreflightScreenCaptureAccess()` returns false on ad-hoc builds even with permissions granted. Now `hasFullRecordingPermission()` bypasses the false-negative directly.
- **Removed auto-open Settings:** `bootEngine()` no longer opens System Settings automatically on every launch.
- **Simplified `startRecording()`:** Removed unnecessary async Task wrapper that caused race conditions.

### macOS App Bundle
- **Signed `.app` bundle** with ad-hoc signature and entitlements (sandbox off, JIT, audio input, unsigned memory).
- **WebRTC.framework embedded** inside `Contents/Frameworks/` with correct `@rpath`.
- **Info.plist** with bundle ID `com.jsm.macdirector`, screen recording and microphone usage descriptions.
- **Entitlements:** `get-task-allow`, `allow-jit`, `allow-unsigned-executable-memory`, `disable-library-validation`, `device.audio-input`.

### Assets Included
- **ElysiumVanguard-v1.7-mac.zip:** Signed macOS `.app` bundle (drag to /Applications).
- **ElysiumVanguard-v1.7.apk:** Android sender APK.
- **MacDirector-v1.7.zip:** Source build (swift build).

### Installation (macOS)
1. Unzip `ElysiumVanguard-v1.7-mac.zip`
2. Drag `Elysium Vanguard.app` to `/Applications`
3. Right-click → Open (first launch only, Gatekeeper)
4. Go to **System Settings → Privacy → Screen Recording** → enable **Elysium Vanguard**
5. Launch the app — no more permission prompts
